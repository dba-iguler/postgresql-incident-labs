# PostgreSQL Incident Labs

Hands-on PostgreSQL troubleshooting and failure scenario labs.

## Scenarios

- Replication lag
- WAL growth
- Patroni failover
- etcd connectivity issues
- Primary node failure
- Long-running queries
- Lock contention
- High CPU queries
- Disk I/O pressure
- Replication slot growth

## How I document each lab

Problem  
-> Symptoms  
-> Detection  
-> Investigation  
-> Root cause  
-> Fix  
-> Validation  
-> Prevention

## Goal

Build troubleshooting habits by breaking things on purpose, investigating the symptoms and documenting the recovery steps.
